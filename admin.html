Подключение к GitHub

Нужно один раз на каждом телефоне. Ключ хранится только на этом устройстве и отправляется только в GitHub.

Как получить: github.com → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → этот репозиторий. Permissions → Repository → Contents: Read and write. Срок — например, 1 год.
